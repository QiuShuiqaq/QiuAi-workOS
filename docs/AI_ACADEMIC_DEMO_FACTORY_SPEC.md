# AI 学术 Demo 工厂规格

## 定位

AI 学术 Demo 工厂用于把学术项目、竞赛项目和科研成果资料快速整理成可现场投屏的本地软件 Demo。

开发阶段不维护 v1/v2 分支。当前模板直接使用正式模板标识：

- `templateId`: `factory_academic_project_demo_v1`
- `roleCode`: `ai-factory-academic-project-demo-v1`

后续发现问题直接修改当前模板，并补回归测试。

## 输入

- 单次生成一个 Demo，不是批量任务。
- 每次最多上传 5 个文件。
- 支持 `Word / PDF / Excel / CSV`。
- 原始文件只在 PC 本地读取，不上传服务器。
- 全局参数支持记忆上一次内容。
- 参数设置区只展示 5 个板块的摘要卡片；每个板块通过齿轮按钮打开独立编辑弹窗。
- 5 个板块都支持启用、跳过、修改标题、调整内容深度和手动编辑。
- 已上传资料可以按板块导入可编辑草稿；没有明确命中内容时保持为空，不强行填充。

## 五个板块

1. 项目首页
2. 研究背景
3. 方法模型
   - 包含算法思路、模型结构、技术路线和公式引用。
4. 数据与验证
   - 包含数据集说明、数据分析、图表、实验对比和可视化演示。
5. 结论与价值

用户手动填写的内容优先级最高，模型只能补空。低置信度或来源不明确的内容进入待补充清单。

## 流程

1. 接收本地资料和用户参数。
2. 使用本地工具提取 Word/PDF/Excel/CSV 内容。
3. 使用文本模型按五个板块保守归类。
4. 生成 `demo-config.json`。
5. 生成本地 Demo HTML 页面。
6. 生成本地演示包 ZIP。

## 编辑与展示

- 项目首页使用项目字段编辑器，保存后在 Demo 中以项目概览展示。
- 研究背景、方法模型、结论与价值使用分项文本编辑器，编辑字段会以独立内容块展示。
- 方法模型支持新增、删除和排序公式；公式保存为纯文本 LaTeX，同时展示公式解释和变量表。
- 数据与验证支持填写数据来源、样本规模、字段说明，并选择真实 Excel/CSV 的分组列、指标列和柱状图/折线图/数据表展示方式。
- Excel/CSV 只展示本地解析得到的真实预览行，列名或数值不足时显示明确提示，不生成虚假对比结果。

## 主产物

输出队列只展示两个主产物：

1. `Demo演示页面`
2. `本地演示包 ZIP`

识别报告、待补充清单、图表摘要和公式清单只作为 ZIP 内部文件或日志详情，不单独占用主输出队列。

## 实现约束

- 第一版公式使用纯文本 LaTeX，不新增公式渲染库。
- 图表使用现有 HTML/SVG 能力，不新增图表库。
- 不增加数据库结构。
- 不把供应商和具体模型写死在节点里。
- 不修改旧数字员工和旧数字工厂的流程、参数和产物定义。
- 共享逻辑修改必须保持旧链路兼容并补回归测试。
